# 문자열 내의 매크로와 매크로 결합

## 문자열 내에서는 매크로의 매개변수 치환 불가

- 문자열 안에서는 치환이 일어나지 않는다.
- 이때 `#` 연산자를 사용한다.

```c
#define STRING_JOB(A, B) "A의 직접은 B입니다."

STRING_JOB(이동춘, 나무꾼) -> "A의 직업은 B이다."
STRING_JOB(한상순, 사냥꾼) -> "A의 직업은 B이다."
```

## 문자열 내에서 매크로 매개변수 치환:  #연산자

- 매개변수 `ABC`에 전달되는 인자를 문자열 `“ABC”`로 치환해라

```c
#define STR(ABC) #ABC

STR(123) -> "123"
STR(12, 23, 34) -> "12, 23, 34"
```

## #를 이용한 문자열 결합

- 둘 이상의 문자열 선언을 나란히 하면, 이는 하나의 문자열 선언으로 인식된다.

```c
// 두 문장은 같은 문장
char * str = "ABC" "DEF";
char * str = "ABCDEF";
```

이를 이용하여 #를 활용

```c
#define STRING_JOB(A, B) #A "의 직업은" #B "입니다."

int main(void)
{
	printf("%s \n", STRING_JOB(이동춘, 나무꾼));
	printf("%s \n", STRING_JOB(한상순, 사냥꾼));
	return 0;
}
```

```c
// 실행 결과
이동춘의 직업은 사냥꾼입니다.
한상순의 직업은 사냥꾼입니다.
```

## 매크로 매개변수들끼리의 결합: ##연산자

- `#define CON(UPP, LOW) UPP ## 00 ## LOW`
    - 매개변수 `UPP`과 `LOW`에 전돨되는 인자를 `UPP00LOW`로 단순히 연결해서 치환해라.
    - int num = CON(22, 77);  →  220077
