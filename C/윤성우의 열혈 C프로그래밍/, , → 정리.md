# * , . , → 정리

## 선언할 때 `*`

```c
int *num;
```

여기서 `*`는 `num`이 포인터 변수라는 것을 선언하는 역할

즉 `num = int를 가리키는 포인터` 

```c
num의 타입 = int *
```

## 사용할 때 `*`

```c
int value = *num;
```

여기서 `*`는 역참조(dereference)이다.

즉, `num에 들어있는 주소` → `그 주소로 이동` → `거기에 있는 int 값` 

그래서

```c
int x = 10;
int *num = &x;

printf("%d", *num);
```

→ `*num`: num에 들어 있는 주소로 가서 10을 가져온다.

## 구조체에서 `*`

```c
typedef struct _listnode
{
    int item;
    struct _listnode *next;
} ListNode;
```

ListNode 구조체 하나를 만드는(선언하는) 코드

```c
ListNode node;
```

ListNode 구조체를 가리키는 포인터를 만드는 코드

```c
ListNode *node;
```

```c
ListNode       → 구조체 자체
ListNode *     → 그 구조체를 가리키는 포인터
```

## 결론

```c
int       = int 값
int *     = int를 가리키는 포인터
int **    = int를 가리키는 포인터를 가리키는 포인터
```

## 구조체 접근

`.` / `→`는 `왼쪽에 있는 것이 구조체 자체냐 포인터냐` 로 결정된다.

- 왼쪽이 구조체 자체면: `.`
- 왼쪽이 포인터이면: `→`

#### 1. 구조체 변수가 있으면 `.`

```c
struct Person {
    int age;
};

struct Person p;
p.age = 27;
```

여기서 `p`는 실제 구조체이다.

```c
p.age
```

p안에 있는 age라는 멤버를 찾아라.

#### 2. 포인터가 있으면 `→`

```c
struct Person p;
struct Person *ptr = &p;
```

`ptr`은 구조체 자체가 아니라 구조체의 주소를 가지고 있는 변수(포인터)

```c
ptr->age
```

ptr이 가지고 있는 주소로 찾아가서 거기에 있는 구조체의 멤버 age를 가져와라.

```c
ptr->age

(*ptr).age
```

둘이 완전 같은 의미다.
