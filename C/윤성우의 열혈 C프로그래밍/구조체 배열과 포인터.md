# 구조체 배열과 포인터

## 구조체 배열의 선언과 접근

- `struct point arr[4];`
    - arr[0] = {arr[0].xpos, arr[0].ypos}
    - arr[1] =  {arr[1].xpos, arr[1].ypos}
    - arr[2] = {arr[2].xpos, arr[2].ypos}
    - arr[3] = {arr[3].xpos, arr[3].ypos}

```c
struct point
{
	int xpos;
	int ypos;
}

int main(void)
{
	struct point arr[3];
	int i;
	for(i=0; i<3; i++)
	{
		printf("점의 좌표 입력: ");
		scanf("%d %d", &arr[i].xpos, &arr[i].ypos);
	}
	for(i=0; i<3; i++)
		printf("[%d, %d] ", arr[i].xpos, arr[i].ypos);
		
	return 0;
}
```

```c
// 실행결과
점의 좌표 입력: 2 4
점의 좌표 입력: 3 6
점의 좌표 입력: 8 9
[2, 4] [3, 6] [8, 9]
```

## 구조체 변수와 포인터

- `(*pptr).xpos=10;`  =  `pptr→xpos=10;`
- `(*pptr).ypos=10;`  =  `pptr→ypos=10;`
- 주로 → 연산자를 많이 사용한다.

```c
struct point
{
	int xpos;
	int ypos;
}

int main(void)
{
	struct point pos1={1,2};
	struct point pos2={100, 200};
	struct point * pptr&pos1;  // 구조체 포인터 변수 pptr 선언
	
	(*pptr).xpos += 4;
	(*pptr).ypos += 5;
	printf("[%d, %d] \n", pptr->xpos, pptr->ypos);
	
	pptr=&pos2;
	pptr->xpos += 1;
	pptr->ypos += 2;
	printf("[%d, %d] \n", pptr->xpos, pptr->ypos);
	return 0;
}
```

```c
// 실행결과
[5, 7]
[101, 202]
```
