# 함수 포임터

## 함수 포인터

- 함수의 이름은 함수가 저장된 메모리 공간을 가리키는 포인터이다. (`함수 포인터`)
- 함수의 이름이 의미하는 주소 값은 `함수 포인터 변수`를 선언해서 저장할 수 있다.
- 함수 포인터 변수를 선언하려면 포인터의 형(type)을 알아야 한다.
    - 함수 포인터의 형 정보에는 `반환형`과 `매개변수 선언` 이 담긴다.

```c
// 앞에 int는 반환형, 뒤에 int는 매개변수형 
// fptr은 포인터
int (*fptr) (int)

int SoSimple(int num1, int num2) {. . . .}
int (*fptr) (int, int);
fptr=SoSimple;
fptr(3, 4);  // SoSimple(3, 4)와 동일한 결과
```

```c
void SimpleAdder(int n1, int n2)
{
	printf("%d + %d \n", n1, n2, n1 + n2);
}

void ShowString(char * str)
{
	printf("%s \n", str);
}

int main(void)
{
	char * str = "Function Pointer";
	int num1=10, num2=20;
	
	void (*fptr1)(int, int) = SimpleAdder;
	void (*fptr2)(char *) = ShowString;
	
	// 함수 포인터 변수에 의한 호출
	fptr1(num1, num2);
	fptr2(str);
	return 0;
}
```

## 형(Type)이 존재하지 않은 void 포인터

- `void * prt`
    - 어떠한 주소 값도 저장이 가능한 void형 포인터
    - 형 정보가 존재하지 않은 포인터 변수이기에 어떠한 주소 값도 저장이 가능
    - 형 정보가 존재하지 않기 때문에 메모리 접근을 위한 *연산은 불가능

```c
void SoSimpleFunc(void)
{
	printf("Im So Simple");
}

int main(void)
{
	int num=20;
	void * ptr;
	
	ptr=&num;  // 뱐수의 num의 주소 값 저장
	printf("%p \n", ptr);  // 001AF974
	
	ptr=SoSimpleFunc;  // 함수 SoSimpleFunc의 주소 값 저장
	prinf("%p \n", ptr);   // 00F61109
	return 0;
}

int main(void)
{
	int num=20;
	void * ptr=&num;
	*ptr=20;  // 컴파일 에러!
	ptr++;    // 컴파일 에러!
	....
}
```
