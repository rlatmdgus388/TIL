# 열거형

## 열거형(`enum`)

변수가 가질 수 있는 값을 미리 정해놓고, 그 값들에 이름을 붙이는 것

- 따로 값을 명시 안해두면 0부터 순차적으로 할당됨

```c
enum State {
		WAITING = 10,
		RUNNING = 20,
		TERMINATED = 30
};
```

```c
WAITING    → 10
RUNNING    → 20
TERMINATED → 30
```

## switch와 함께 쓰면 좋다.

- 숫자로 했다면 `if (state == 1)` 이라 해야 하는데, 문자로 `if (state == RUNNING)`이라 표현해 읽기 좋아짐.

```c
enum State {
    WAITING,
    RUNNING,
    TERMINATED
};

enum State state = RUNNING;

switch (state) {
    case WAITING:
        printf("대기 중");
        break;

    case RUNNING:
        printf("실행 중");
        break;

    case TERMINATED:
        printf("종료");
        break;
}
```

## 열거형과 사용 예시

```c
enum Type {
    INT,
    DOUBLE
};

struct Data {
    enum Type type;

    union {
        int number;
        double real;
    };
};
```

여기선 현재 `union`에선 어떤 종류의 데이터를 사용하고 있는지 표시하는 표지판 역할을 한다.

```c
struct Data data;

data.type = INT;
data.number = 20;

data.type = DOUBLE;
data.real = 7.15;
```
