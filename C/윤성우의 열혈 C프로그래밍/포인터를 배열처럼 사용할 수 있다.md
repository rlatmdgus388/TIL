# 포인터를 배열처럼 사용할 수 있다.

`* 연산자`: 포인터가 가리키는 메모리를 참조(반환)

- 선언할 때의 `*` (`int **dp1`)
    - 이 변수는 이중 포인터 변수이다 라고 타입을 정의하는 역할. (포인터 변수의 주소를 담겠다)
- 실행 코드에서의 `*` (`*dp1`)
    - 포인터 `dp1`이 가지고 있는 주소로 직접 찾아가라(반환해라)

`& 연산자`: 피연산자의 주소값 반환

포인터를 그냥 등호로 생각하자

## 배열의 이름은 포인터이다.

배열의 이름은 단순 배열의 시작 주소 값이 아니라, 시작 주소 값을 가리키는 포인터이다. 단순한 주소 값이 아닌 이유는 메모리 접근에 사용되는 `*`연산이 가능하기 때문이다.

```c
int main(void)
{
	int arr[3] = {0, 1, 2}
	printf("배열의 이름: %p \n", arr);         // 배열의 이름: 0012FF50
	printf("첫 번째 요소: %p \n", &arr[0]);    // 첫 번째 요소: 0012FF50
	printf("두 번째 요소: %p \n", &arr[1]);    // 두 번째 요소: 0012FF54
	printf("세 번째 요소: %p \n", &arr[2]);    // 세 번째 요소: 0012FF58
	// arr = &arr[i];  // 이 문장은 컴파일 에러를 일으킨다.
	// 출력값을 보면 배열 요소간 주소 값의 크기는 4바이트임을 알 수 있다.
	return 0;
}
```

- 아래와 같이 배열의 이름으로 `포인터 연산`을 하고 있다.

```c
int main(void)
{
	int arr1[3]={1, 2, 3};
	double arr2=[3]={1.1, 2.2, 3.3};
	
	printf("%d %g \n", *arr1, *arr2);     // 1 1.1
	*arr1 += 100;
	*arr2 += 120.5;
	printf("%d %g \n", arr1[0], arr2[0]); // 101 121.6
	retunr 0;
}
```

## 포인터를 배열의 이름처럼 사용할 수 있다.

- `[ ]`  연산자는 내부적으로 포인터 연산으로 자동 변환된다.
    - `A[B]`는 `*(A + B`)와 동일한 문장
    - 예) `arr[1]`과 `ptr[1]`
        - `arr[1]` → `*(arr + 1)`
            - 배열 이름 `arr`는 첫 번째 요소의 주솟값이다.
            - 여기에 `+ 1`을 하면 포인터 연산 규칙에 의해 `sizeof(int)` 만큼 더해져 다음 요소의 주소가 된다.
        - `ptr[1] → *(ptr + 1)`
            - 포인터 변수 `ptr`도 `arr`와 동일한 주소값을 가지므로 동일하게 처리됨.

```c
int main(void)
{
	int arr[3]={15, 25, 35}
	int * ptr&arr[0];   // int * ptr=arr; 과 동일한 문장
	
	printf("%d %d \n", ptr[0], arr[0]);   // 15 2
	printf("%d %d \n", ptr[1], arr[1]);   // 25 25
	printf("%d %d \n", ptr[1], arr[1]);   // 35 35
	printf("%d %d \n", *ptr, *arr);	      // 15 15
	return 0;
}
```
