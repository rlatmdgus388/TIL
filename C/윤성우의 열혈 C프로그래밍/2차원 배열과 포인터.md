# 2차원 배열과 포인터

## 2차원 배열을 함수의 인자로 전달

- 2차원 배열의 매개변수 언어 방법
    - `int (*parr1)[7]`, `double (*parr2)[5]`
    - `int parr1[][7]`, `double parr2[][5]`

```c
void ShowArr2DStyle(int (*arr)[4], int column)
{
	int i, j;
	for (i=0; i<column; i++)
	{
		for(j=0; j<4; j++)
			printf("%d", arr[i][j]);
		printf("\n");
	}
	printf("\n");
}

int Sum2DArr(int arr[][4], int column)
{
	int i, j, sum=0;
	for(i=0; i<column; i++)
		for(j=0; j<4; j++)
			sum += arr[i][j];
	return sum;
}

for main(void)
{
	int arr1[2][4]={1, 2, 3, 4, 5, 6, 7, 8};
	int arr2[3][4]={1, 1, 1, 1, 3, 3, 3, 3, 5, 5, 5, 5};
	//배열의 세로 길이 계산 방식
	ShowArr2DStyle(arr1, sizeof(arr1)/sizeof(arr1[0]));
	ShowArr2DStyle(arr1, sizeof(arr2)/sizeof(arr2[0]));
	printf("arr1의 합: %d \n", Sum2DArr(arr1, sizeof(arr1)/sizeof(arr1[0])));
	printf("arr2의 합: %d \n", Sum2DArr(arr2, sizeof(arr2)/sizeof(arr2[0])));
	return 0;
}

// 1 2 3 4
// 5 6 7 8
// 
// 1 1 1 1
// 3 3 3 3
// 5 5 5 5

//arr1의 합: 36
//arr2의 합: 36
```

## 2차원 배열에서도 arr[i]와 *(arr+i)는 같다

- `arr[i] == *(arr+i)`
- int arr[3][2] = {{1,2}, {3,4}, {5,6}};
    - arr[2][1] = 4;
    - (*(arr+2)[1]=4;
    - *(arr[2]+1)=4;
    - *(*arr2+2)+1)=4;
