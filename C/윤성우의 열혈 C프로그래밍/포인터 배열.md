# 포인터 배열

1. **`int arr[10];` (일반 1차원 배열)**
    - **배열의 요소 타입:** `int` (정수)
    - **배열 이름 `arr`의 평가 타입:** 첫 번째 원소(`int`)의 주소이므로 **`int *` (1차 포인터)**
2. **`int * parr[20];` (1차원 포인터 배열)**
    - **배열의 요소 타입:** `int *` (포인터)
    - **배열 내부 저장값:** `parr[0]`, `parr[1]` ... 각각이 모두 주소값을 담는 포인터 변수입니다.
    - **배열 이름 `parr`의 평가 타입:** 첫 번째 원소(`int *`)의 주소이므로 **`int **` (2차 포인터 / 이중 포인터)**

## 배열 포인터와 포인터 배열의 구분

- int * whoA [4];  → 포인터 배열: 포인터 변수로 이루어진 배열
- int (*whoB) [4]; → 배열 포인터: 배열을 가리키는 포인터 변수

```c
int main(void)
{
	int num1=10, num2=20, num3=30, num4=40;
	int arr2d[2][4]={1, 2, 3, 4, 5, 6, 7, 8};
	int i, j;
	
	int * whoA[4]={&num1, &num2, &num3, &num4};  // 포인터 배열
	int (*whoB)[4]=arr2d;  // 배열 포인터
	
	printf("%d %d %d %d \n", *whoA[0], *whoA[1], *whoA[1], *whoA[2], *whoA[3]);
	for(i=0; i<2; i++)
	{
		for(j=0; j<4; j++)
			printf("%d ", whoB[i][j]);
		printf("\n");
	}
	return 0;
}
```
