# 구조체 vs 공용체

## 구조체와 공용체

- `구조체`는 멤버들이 각각 자기 메모리를 가지고, `공용체`는 모든 멤버가 같은 메모리 공간을 공유한다.

#### 구조체

```c
struct Box {
    int mem1;
    int mem2;
    double mem3;
};

struct Box box;
```

```c
box
┌──────────────┐
│ mem1 (int)   │
├──────────────┤
│ mem2 (int)   │
├──────────────┤
│ mem3 (double)│
└──────────────┘
```

각 멤버가 각자의 공간을 차지해, `mem1`에 값을 넣아도 `mem2`, `mem3`에는 아무 영향이 없음.

#### 공용체

```c
typedef union ubox
{
    int mem1;
    int mem2;
    double mem3;
} UBox;

Ubox ubx;
```

```c
       같은 메모리 공간
┌──────────────────────┐
│                      │
│   mem1               │
│   mem2               │
│   mem3               │
│                      │
└──────────────────────┘
```

`mem1`, `mem2`, `mem3`가 같은 메모리를 공유

## 공용체의 값 할당

아래 코드를 실행하면 공용체 메모리에 값 20을 저장한다.

```c
Ubox ubx;

ubx.mem1 = 20;
```

그 후 다른 멤버 변수인 mem2를 프린트하면 mem1과 같은 값이 출력된다. mem1과 mem2는 별도의 메모리 공간이 똑같은 메모리를 보고 있기 때문이다.

```c
printf("%d\n", ubx.mem2);  // 20
```

하지만 여기에 `double`값을 넣으면 어떻게 될까. 기존의 20 값은 7.15로 덮어써진다.

```c
ubx.mem3 = 7.15;
```

따라서 print를 하면 저렇게 값이 출력된다.

```c
printf("%d\n", ubx.mem1);
printf("%d\n", ubx.mem2);
printf("%g\n", ubx.mem3);

// -1717986918
// -1717986918
// 7.15
```

## 출력값에서 이상한 정수 값이 나오는 이유

- 메모리에 저장된 값은 `double`형 값인데 `mem1`과 `mem2`는 int형 타입이므로 값이 이상하게 나옴.
