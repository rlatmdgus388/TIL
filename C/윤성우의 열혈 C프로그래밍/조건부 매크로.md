# 조건부 매크로

## #if … #endif: 참이라면

- `#if 조건식`
    - 조건식을 계산해서 참/거짓 판단
    - 조건이 참이면 ~ #endif 까지 컴파일 대상에 포함

```c
#define ADD 1
#define MIN 0

int main(void)
{
	int num1, num2;
	printf("두 개의 정수 입력: ")
	scanf("%d %d", &num1, &num2);

#if ADD  // ADD가 참이라면
	printf("%d + %d = %d \n", num1, num2, num1+num2);
#endif

#if MIN  // MIN이 참이라면
	printf("%d - %d = %d \n", num1, num2, num1 - num2);
	return 0;
}
```

```c
두 개의 정수 입력: 5 4
5 + 4 = 9
```

## #ifdef … #endif: 정의되었다면

- `#ifdef 매크로`
    - 매크로 정의 여부로 참/거짓 판단
    - 특정 매크로가 정의되었다면 ~ #endif까지 컴파일 대상에 포함

```c
// #define ADD 1
#define MIN 0

int main(void)
{
	int num1, num2
	printf("두 개의 정수 입력: ");
	scanf("%d %d", &num1, &num2);
	
#ifdef ADD  // 매크로 ADD기 정의되었다면
	printf("%d + %d = %d \n", num1, num2, num1 + num2);
#endif

#ifdef MIN  // 메크로 MIN이 정의되었다면
	printf("%d - %d = %d \n", num1, num2 num1 - num2);
#endif

	return 0;
}
```

```c
두 개의 정수 입력: 7 2
7 - 2 = 5
```

## #ifndef … #endif: 정의되지 않았다면

- 위에 내용과 동일

## #else 삽입: #if, #ifdef, #ifndef에 해당

- #else를 추가해서 조건이 참이 아닌 경우에 컴파일의 대상에 포함시킬 문장들을 구성할 수 있다.

```c
#define HIT_NUM 5

int main(void)
{
#if HIT_NUM == 5
	puts("매크로 상수 HIT_NUM은 현재 5이다.";
#else
	puts("매크로 상수 HIT_NUM은 현재 5가 아니다.";
#endif
	return 0;
}
```

## #elif의 삽입: #if에만 해당

- `#elif`와 `#else`를 추가해서 if ~ else if ~ else 구문과 동일한 형태를 구성할 수 있다.
