# 3. 자동 형변환

날짜: 01. 스코프 형변환

## 형변환

- 작은 범위에서 큰 범위로는 당연히 값을 넣을 수 있음
    - 예) `int` → `long` → `double`
    
    ```java
    int intValue = 10;
    long longValue;
    
    longValue = intValue; // int -> long
    ```
    
- 큰 범위에서 작은 범위는 아래와 같은 문제 발생
    - 소수점 버림
    - 오버플로우

## 자동 형변환

- 자바는 기본적으로 같은 타입에 값을 대입할 수 있음.
    - 작은 범위의 형을 큰 범위의 형으로 맞춤

```java
//intValue = 10
doubleValue = intValue
doubleValue = (double) intValue //형 맞추기
doubleValue = (double) 10 //변수 값 읽기
doubleValue = 10.0 //형변환
```

- 작은 볌위 숫자 타입에서 큰 범위 숫자 타입으로의 대입은 위와 같이 직접 형변환을 하지 않아도 형변환이 자동으로 이루어짐.
