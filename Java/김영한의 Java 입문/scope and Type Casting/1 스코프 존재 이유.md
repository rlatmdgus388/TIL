# 1. 스코프 존재 이유

날짜: 01. 스코프 형변환

```jsx
package scope;

public class Scope3_1 {
	public static void main(String[] args) {
		int m = 10;
		int temp = 0;
		if (m > 0) {
			temp = m * 2;
			System.out.println("temp = " + temp);
		}
		System.out.println("m = " + m);
	}
}
```

- 이 코드가 좋은 코드라 보기 어려운 이유
    1. 비효율적인 메모리 사용: `temp`는 `if` 코드 블록에서만 사용하지만, `main()` 코드 블록이 종료될때까지 메모리에 유지된다. 만약 `if` 코드 블록 안에 `temp`를 선언했다면 더 효율적인 메모리를 사용할 수 있다.
    2. 코드 복잡성 증가: `if` 코드 블록이 끝나도 `main` 어디서나 `temp`를 여전히 접근할 수 있다. 누군가 이 코드를 유지보수 할 때 `m`은 물론 `temp`까지 계속 신경써야함.

## temp의 스코프를 꼭 필요한 곳으로 한정

```java
package scope;

public class Scope3_1 {
	public static void main(String[] args) {
		int m = 10;
		if (m > 0) {
			int temp = m * 2;
			System.out.println("temp = " + temp);
		}
		System.out.println("m = " + m);
	}
}
```
