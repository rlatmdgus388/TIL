# 4. 명시적 형변환

날짜: 01. 스코프 형변환

## 큰 범위에서 작은 범위로 대입하는 경우

```java
package casting;

public class Casting2 {

	public static void main(String[] args) {
		double doubleValue = 1.5;
		int intValue = 0;
		
		//intValue = doubleValue; //컴파일 오류 발생
		intValue = (int) doubleValue; //형변환
		System.out.println(intValue); //출력:1
	}
}
```

`//intValue = doubleValue; //컴파일 오류 발생`

```java
java: incompatible types: possible lossy conversion from double to int
//java: 호환되지 않는 유형: double에서 int로의 가능한 손실 변환
```

- int형은 double형보다 숫자의 표현 범위가 작다.  그리고 실수를 표현할 수 없다.
- 따라서 이 경우 숫지의 손실되는 문제가 발생할 수 있음. 따라서 자바에서 이런 경우 컴파일 오류 발생시킨다.

---

## 명시적 형변환 과정

```java
//doubleValue = 1.5
intValue = (int) doubleValue;
intValue = (int) 1.5; //doubleValue에 있는 값을 읽는다.
intValue = 1; //(int)로 형변환 한다. intValue에 int형인 숫자 1을 대입한다.
```

- 형변환을 한다고 해서 `doubleValue` 자체의 타입이 변경되거나 그 안에 있는 값이 변경되는 것은 아니다.
- `doubleValue` 에서 읽은 값을 형변환 하는 것이다. `doubleValue` 안에 들어있는 값은 `1.5`
로 그대로 유지된다.
- 자바에서 변수의 값은 대입연산자(=)를 사용해서 직접 대입할 때만 변경된다.

## 형변환과 오버플로우

```java
package casting;

public class Casting3 {

	public static void main(String[] args) {
		long maxIntValue = 2147483647; //int 최고값
		long maxIntOver = 2147483648L; //int 최고값 + 1(초과)
		int intValue = 0;
		
		intValue = (int) maxIntValue; //형변환
		System.out.println("maxIntValue casting=" + intValue); //출력:2147483647
		
		intValue = (int) maxIntOver; //형변환
		System.out.println("maxIntOver casting=" + intValue); //출력:-2147483648
	}
}
```

- 리터럴
    - 코드에 적어 둔 값 그 자체를 의미. 즉, 변수에 넣는 변하지 않는 데이터 값을 말한다.
    - 상수랑 차이점이 뭔데?
        - 상수는 변하지 않는 변수를 뜻한다.
    - 정수 형태의 리터럴은 컴파일러가 해석할 때 기본적으로 `int` 형으로 해석한다.
    - 따라서 위 코드의 `maxIntOver` 의 경우, `int` 형의 최대 범위를 넘었기 때문에 `long`을 뜻하는 접미사 `L`을 붙여야함.

#### 출력 결과

```java
maxIntValue casting=2147483647
maxIntOver casting=-2147483648
```

- 정상 범위
    - `maxIntVaue`의 경우 `int`로 표현할 수 있는 범위에 포함되기 때문에 다음과 같이 `long` → `int`로 형변환을 해도 아무런 문제가 없다.
        - `intValue = (int) maxIntValue; //형변환`
        
        ```java
        maxIntValue = 2147483647; //int 최고값
        intValue = (int) maxIntValue; //변수 값 읽기
        intValue = (int) 2147483647L; //형변환
        intValue = 2147483647;
        ```
        
- 초과 범위
    - `maxIntOver`의 경우 `int`로 표현할 수 있는 숫자인 `2147483647`보다 1큰 숫자를 입력했다.  이 경우 `int`로 표현할 수 있는 범위에 포함되기 때문에 다음과 같이 `long` → `int`로 형변환을 해도 아무런 문제가 없다.
        - `intValue = (int) maxIntOver; //형변환`
        
        ```java
        maxIntOver = 2147483648L; //int 최고값 + 1
        intValue = (int) maxIntOver; //변수 값 읽기
        intValue = (int) 2147483648L; //형변환 시도
        intValue = -2147483648;
        ```
        
        - 이렇게 기존 범위를 초과해서 표현하게 되면 전혀 다른 숫자가 표현되는데, 이 현상을 오버플로우라 한다.
