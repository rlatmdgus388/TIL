# 1. 배열의 선언과 생성

날짜: 02. 배열

## 배열의 선언과 생성

- 배열은 같은 타입의 변수를 사용하기 편하게 하나로 묶어둔 것

```java
package array;

public class Array1Ref1 {
	public static void main(String[] args) {
		int[] students; //배열 변수 선언
		students = new int[5]; //배열 생성

		//변수 값 대입
		students[0] = 90;
		students[1] = 80;
		students[2] = 70;
		students[3] = 60;
		students[4] = 50;
	
		//변수 값 사용
		System.out.println("학생1 점수: " + students[0]);
		System.out.println("학생2 점수: " + students[1]);
		System.out.println("학생3 점수: " + students[2]);
		System.out.println("학생4 점수: " + students[3]);
		System.out.println("학생5 점수: " + students[4]);
	}
}
```

1. 배열 변수 선언

```java
int[] students; //1. 배열 변수 선언
```

- 배열을 사용하려면 위의 코드와 같이 배열 변수를 선언해야함.
- 배열 변수를 선언했다고 아직 배열이 만들어진게 아님.
    - 배열 변수에는 원소 하나 하나 값이 아닌 배열을 담음
    
1. 배열 생성

```java
tudents = new int[5]; //2. 배열 생성
```

- 배열을 사용하려면 배열을 생성해야함.
- `new int[5]`라 입력하면 5개의 `int`형 변수가 만들어짐
- 초기화
    - 자바는 배열을 생성할 때 자동으로 내부값을 초기화 한다.
1. 배열 참조값 보관
    - `new int[5]`로 배열을 생성 하면 배열의 크기만큼 메모리를 확보한다.
        - `int`형을 5개 사용하면 `4byte * 5` → `20byte` 를 확보한다.
    - 배열을 생성하고 나면 배열의 참조값(주소)를 반환
        - 앞서 선언한 배열 변수인 `int[] students`에 생성된 배열의 참조값을 보관한다.

```java
int[] students = new int[5]; //1. 배열 생성
int[] students = x001; //2. new int[5]의 결과로 x001 참조값 반환
students = x001 //3. 최종 결과
```

참조값을 확인하고 싶다면 배열의 변수를 출력해보면 된다.

```java
System.out.println(students); //[I@4617c264 @앞의 [I는 int형 배열을 뜻한다. @뒤에 16진
수는 참조값을 뜻한다.
```
