# 2. 기본형 vs 참조형

날짜: 02. 배열

## **기본형** vs **참조형**

자바의 변수 데이터 타입을 가장 크게 보면 기본형과 참조형으로 분류할 수 있다. 

사용하는 값을 직접 넣을 수 있는 기본형, 그리고 방금 본 배열 변수와 같이 메모리의 참조값을 넣을 수 있는 참조형으로 분류할 수 있다.

- 기본형(Primitive Type): 우리가 지금까지 봤던 `int` , `long` , `double` , `boolean` 처럼 변수에 사용할 값을직접 넣을 수 있는 데이터 타입을 기본형(Primitive Type)이라 한다.
- 참조형(Reference Type): `int[] students` 와 같이 데이터에 접근하기 위한 참조(주소)를 저장하는 데이터타입을 참조형(Reference Type)이라 한다. 객체도 마찬가지.

## 배열이 참조형을 사용하는 이유 (참고)

기본형은 모두 사이즈가 정해져 있다.

```java
int i; // 4byte
long l; // 8byte
double d; // 8byte
```

그런데 배열은 다음과 같이 동적으로 사이즈를 변경할 수 있다.

```java
int size = 10000;  // 사용자가 입력한 값을 넣었다고 가정
new int[size];  // 이 코드가 실행되는 시점에 배열의 크기가 정해짐
```

- 기본형은 선언과 동시에 크기가 정해짐. 따라서 크기를 동적으로 바꿀 수 없다. 반면, 배열과 같은 참조형은 크기를 동적으로 할당할 수 있다.
    - 예로 `Scanner`를 사용해서 사용자의 입력에 따라 변수의 값이 변하고, 배열의 크기도 달라질 수 있다. 이런 것을 동적 메모리 할당이라 한다. 이처럼 동적으로 크기가 변해 유연성을 제공함
- 참조형은 메모리에 저장된 객체나 배열을 참조하기 때문에 더 복잡한 데이터 구조를 만들고 관리 할 수 있다. 반면, 기본형은 더 빠르고 메모리 효율적으로 처리.
